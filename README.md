# Web Design Master

一套端到端的網站設計與前端交付 Skill，協助把需求、視覺方向、介面實作、響應式行為、無障礙及驗收串成同一個工作流程。適用於新建網站或網頁應用、依設計稿實作、改善現有介面，以及檢視／稽核網站。

## 涵蓋範圍

- 盤點現有專案、技術堆疊、內容、設計慣例與驗收條件。
- 建立設計方向、內容層級、設計 token、元件及必要狀態。
- 實作語意化介面、手機優先的響應式版面、互動與動效。
- 檢查鍵盤操作、減少動態效果需求及 WCAG 2.2 AA 無障礙要點。
- 執行專案現有的建置／測試，並進行瀏覽器、視覺品質與回歸檢查；清楚列出未驗證之處。

Skill 會優先沿用專案既有架構，不會為了外觀任意更換框架。檢視／稽核模式只回報優先事項，不會在未獲要求時直接修改程式碼。

## 安裝

此 Skill 由 `SKILL.md` 與 `references/` 參考文件組成。請將整個 repository 放入你所使用之 AI 工具支援的 Skills 目錄；該目錄位置依工具而異。不要只複製 `SKILL.md`，否則工作流程連結的參考文件會缺失。

```bash
git clone https://github.com/samulee003/website-skill.git web-design-master
```

之後把 `web-design-master` 資料夾移至該工具的 Skills 目錄，並依工具要求重新載入或啟用 Skill。若工具提供從 GitHub 匯入 Skill 的功能，也可匯入此 repository，並確認 `references/` 一併保留。

## 使用

啟用 Skill 後，直接描述要完成的網站工作，例如：

- 「根據這份產品簡介建立一個手機優先的 landing page。」
- 「依照附上的設計稿實作這個頁面，並檢查不同螢幕寬度。」
- 「改善現有網站的導覽和表單互動，但保留目前的技術堆疊。」
- 「稽核這個頁面的視覺、響應式及無障礙問題；先列出發現，不要修改。」

工作時會按需要讀取 `references/` 中的專題指引；實際建置、瀏覽器檢查及測試能力取決於所使用工具和專案環境。
